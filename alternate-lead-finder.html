Alternate Lead Finder

Turning closed, unresponsive leads into fresh people to contact

The Alternate Lead Finder is a weekly automation. When an outreach sequence goes cold and the lead stops responding, it looks up a different contact at the same company — ideally a decision-maker in a role we care about — so sales has someone new to approach instead of hitting a dead end. Every new lead it finds is recorded, added to the sales sheet, and summarised in an email to Liv for review.

What it does

Each week the automation takes the leads whose email sequences have closed without a reply and, for every one, tries to find another person at the same organisation worth contacting.

  • Reads the unresponsive (closed) leads that are waiting to be processed.
  • Uses Hunter.io to find other people at the same company (matched by email domain).
  • Prioritises the roles we most want to reach; falls back to any contact if none of those roles are available.
  • Skips anyone whose email is already one of our ActiveCampaign contacts, so we don't double up.
  • Saves each new lead, adds it to the sales sheet, and emails Liv a preview.

When it runs

Two scheduled steps run every Monday, 55 minutes apart (Philippine time):

  • 6:00 AM — Closed Threads Processing. An n8n workflow gathers the week's newly closed / unresponsive threads and lists them ready to be worked on.
  • 6:55 AM — Alternate Lead Finder. This automation processes that list, finds the alternate contacts, and files the results.

You do not need to start either one by hand — but you can run the finder on demand at any time (see "Running it manually" below).

Which contacts it looks for

Priority roles

It prioritises finding people in these roles, and will record up to five of them per company:

  • HR
  • Executive Assistant (EA)
  • Events Manager
  • Conference Manager
  • Marketing Manager
  • Communications Manager
  • Learning & Development Manager
  • People & Culture Manager

Fallback

If nobody at the company matches those roles, it records just one contact of any role, so the company still gets a follow-up option rather than being skipped entirely.

Lead type

Each new lead is tagged as either soc med or cold, based on which sequence the original unresponsive lead came from. For soc-med leads, the original speaker and event are carried across so the context isn't lost.

Where the results go

Every new lead lands in three places:

  • The alternate_leads table — the master record of every alternate lead found, with the company, contact name, role, email, lead type, and the original thread it came from.
  • The sales sheet — new leads are appended to the alternate_leads_found tab of the sales spreadsheet, ready for the team to action. Open the sales sheet.
  • An email to Liv — after new leads are added, Liv receives a summary email with a preview table of the leads and a link to the sheet for review.

How duplicates are avoided

Before saving any contact, the automation checks it isn't someone we already know:

  • It first checks against our cached list of ActiveCampaign contacts.
  • If that cached list happens to be empty (it refreshes once a day and can briefly be blank), it checks ActiveCampaign directly instead, so the safety net is never lost.
  • It also skips the original unresponsive contact and anything it has already recorded, so the same person is never added twice.

Running it manually

You can trigger the finder yourself without waiting for Monday. A file named manual_invoke.txt sits in the project folder with ready-to-paste commands for Windows Command Prompt.

  • Normal run — processes all outstanding closed leads, exactly like the Monday schedule.
  • Small test batch — processes only the first couple of leads, to check things are working without using up much of the monthly Hunter.io allowance.
  • Append + email only — pushes any leads still waiting into the sheet and emails the preview, without doing any new lookups.
  • Health check — confirms the sheet, email, and ActiveCampaign connections are all working, without processing anything.

A normal run replies instantly with a "started" message and then keeps working in the background for a minute or two — that "started" reply means it launched successfully, not that anything went wrong. Check the results in the alternate_leads table, the sales sheet, or Liv's inbox.

Good to know

  • Hunter.io allowance. The lookup service is currently on the free plan, which allows about 50 company searches per month. A single run can only enrich around 50 companies, so clearing a large backlog in one go needs a paid Hunter.io plan.
  • Nothing is wasted on errors. If a lookup fails or the monthly allowance runs out, that lead is simply left for next time rather than being marked done — so it will be retried, not lost.
  • The sheet tab is set up automatically. The first time it runs, it creates the column headings on the alternate_leads_found tab if they aren't there yet.
